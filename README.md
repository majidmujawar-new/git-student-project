# git-student-project

This is a sample Git demo project repository for learning basic Git and Python scripting.

## Project files

- `hello.py` - Prints a welcome message and demonstrates a simple Python program.
- `factorial.py` - Calculates the factorial of a non-negative integer entered by the user.
- `README.md` - Project overview and documentation.

## Current changes

The repository now includes a simple Python greeting script and a factorial calculator program, showing basic project structure and version-control practice.
